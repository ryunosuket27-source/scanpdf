# スキャンPDF

写真を撮ってPDFにするWebアプリ．広告なし，画像は端末の外に出ない．

- 撮影／写真から追加
- 書類の輪郭を自動検出して四隅を合わせる（手動で調整も可）
- 台形補正・影取り（くっきり／白黒）
- 並べ替え・回転・削除
- PDF作成 → 共有シートで保存

## iPhoneのホーム画面に追加

1. SafariでこのサイトのURLを開く
2. 共有ボタン →「ホーム画面に追加」

一度開けばオフラインでも動く．

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（外部ライブラリなし） |
| `manifest.webmanifest` | ホーム画面用の設定 |
| `sw.js` | オフライン対応 |
| `icon-*.png`, `apple-touch-icon.png` | アイコン |
